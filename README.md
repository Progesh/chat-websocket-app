# Chat application based on websockets using Javascript and Nodejs

A real-time chat application built using WebSockets with JavaScript and Node.js. This project demonstrates how to create a seamless and interactive chat experience using WebSockets for real-time communication.

# Features
- Real-time messages powered by WebSockets.
- User-friendly interface built with HTML and CSS.
- Lightweight and efficient backend built with Node.js.

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- WebSocket Protocol: For real-time communication

## Installation
Follow these steps to get the application up and running on your local machine:

1. Clone the repository:
<pre>
git clone https://github.com/Progesh/chat-websocket-app.git  
</pre>

2. Navigate to the project directory:
<pre>
cd chat-websocket-app  
</pre>

3. Install the dependencies:
<pre>
npm install  
</pre>

4. Start the application:
<pre>
node server.js  
</pre>

## Usage
1. Open your browser and navigate to http://localhost:3000.
2. Start chatting with other users in real-time.
